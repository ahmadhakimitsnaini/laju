## 📌 Deskripsi Proyek
Repositori ini berisi *source code* untuk website portofolio studi kasus UI/UX secara mendalam yang membahas aplikasi *ride-hailing* bernama **LAJU**.

Tujuan utama dari website ini adalah mentransformasi presentasi studi kasus desain UI/UX (yang biasanya berupa file PDF atau presentasi statis) menjadi pengalaman web yang dinamis, interaktif, dan premium. Pengunjung dapat mengeksplorasi proses desain (*Design Thinking*) dari awal hingga akhir secara langsung di dalam peramban web mereka.

## 🌟 Fitur Utama Website
* **Smooth Parallax Hero Section**: Menampilkan *grid* desain layar aplikasi yang bergerak secara asinkron (efek *parallax*) saat halaman di-*scroll*.
* **Interactive Ideate Tabs**: Sistem *tab* interaktif untuk berpindah antardokumen arsitektur dan sistem desain (Figma embeds) tanpa membebani performa *loading* browser.
* **Immersive Prototype Mockup**: Tampilan purwarupa *(High-Fidelity Flow)* Figma yang dibungkus oleh desain perangkat iPhone 17 Pro Max menggunakan CSS asli, memberikan impresi "native app" bagi pengunjung.
* **Smart Glassmorphic Navbar**: *Navbar* berdesain transparan yang responsif; mengecil secara halus (*shrink*) saat pengguna men-scroll ke bawah dan secara otomatis menyorot menu navigasi sesuai bagian (*section*) yang sedang dibaca.
* **Thematic Dark Mode Aesthetic**: Desain dasar berpusat pada warna `#1E1E1E` gelap untuk memberikan nuansa premium *tech-startup*, dipadukan dengan aksen *Deep Tech Blue* (`#0052CC`) dan *Warm Tangerine* (`#FF7A00`).

## 🗺️ Struktur Proses Desain (*Design Thinking*)
Konten website dibagi berdasarkan tahapan standar industri UI/UX:
1. **Overview**: Konteks, peran, *timeline*, dan pemahaman awal tentang masalah.
2. **Define**: Analisis masalah pengguna, *pain points*, dan penentuan tujuan utama.
3. **Ideate**: *Brainstorming*, *Information Architecture*, *User Flow*, dan *Design System*.
4. **Prototype**: Hasil desain visual (*High-Fidelity*) yang bisa diinteraksikan langsung.
5. **Validasi (Test)**: Metrik pengujian dan iterasi desain akhir.

## 🛠️ Tech Stack
* **Framework:** [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animasi:** [Framer Motion](https://www.framer.com/motion/)
* **Ikon:** [Lucide React](https://lucide.dev/)

## 🚀 Cara Menjalankan Proyek Secara Lokal

Jika Anda ingin mengkloning dan memodifikasi proyek ini:

1. **Clone repositori**
   ```bash
   git clone https://github.com/ahmadhakimitsnaini/laju.git
   cd "Portofolio UIUX"
   ```

2. **Instal dependensi**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**
   ```bash
   npm run dev
   ```

4. Buka `http://localhost:5173` di peramban web Anda.
